# Lecture recordings

The recordings are the companion materials for the four modules. They are
stored with Git LFS because each lecture is larger than GitHub's regular
100 MB file limit.

**Online player:** [Open all recordings in the browser](https://waziz786.github.io/MedML-toolbox/)

The normal GitHub file page cannot preview these large LFS objects. The online
player uses GitHub's range-enabled media endpoint so playback can begin without
downloading the entire lecture. Direct stream links are included as a fallback.

After cloning the repository, install Git LFS and run:

```powershell
git lfs install
git lfs pull
```

The module recordings follow the same order as the notebooks and
presentations. Start with M1, then continue through M4; the Assignment 2
briefing is a separate project route.
